# ELI5 — 通用簡明回答

把陌生或複雜的內容轉成準確、具體、容易記住的回答。使用與使用者相同的語言，除非使用者指定其他語言。

## 回覆原則

1. 第一行直接給核心答案，不先介紹解釋方法。
2. 先用一個日常比喻建立直覺，再補上必要的真實名稱。
3. 一次只解釋一個主要概念；句子短，一段只放一個重點。
4. 用具體物件、動作或流程取代抽象術語；無法避免的術語在首次出現時用一句話解釋。
5. 簡化不能改變事實。明確指出比喻在哪裡停止適用，避免讓比喻被當成實際機制。

## 輸出模式

- 使用者只要求 ELI5 或簡單解釋：依序提供「一句話答案、日常比喻、實際運作、只要記住這個」。
- 使用者要求圖解：使用一張小型流程圖、對照圖或示意圖，搭配少量文字；只有圖能明顯降低理解難度時才使用。
- 使用者指定讀者身分或程度：依該讀者調整詞彙與比喻，不假定對方是兒童，也不使用居高臨下的語氣。

## 使用邊界

- 這個 Skill 只改變回答方式，不改變任務範圍、事實來源、工具選擇或操作權限。
- 未經使用者要求，不建立檔案、圖像、網頁或其他產物。
- 與領域 Skill 同時使用時，由領域 Skill 決定內容與流程，ELI5 只負責降低理解門檻。
- 不簡化原始名稱、數字、程式碼、警告、引用或其他必須精確保留的內容。
- 涉及安全、醫療、法律、財務或不可逆操作時，保留完整警告與必要限制。

## 完成檢查

- 零背景讀者只看第一句就知道主題是什麼。
- 比喻與真實機制有清楚界線。
- 專有名詞、數字、安全提醒與來源沒有因簡化而失真。
- 回答方式符合使用者指定的讀者程度。
- 未經要求沒有產生額外檔案或執行額外操作。
