# 05 — 克菲爾與 SCOBY 型發酵乳（Kefir & SCOBY）

> 建立日期：2026-07-31  
> 為何獨立成章：kefir 與常溫優格**同溫區但不同性質**。若沿用優格的分類軸（只看適溫與能否傳代），會得出錯誤預期。

---

## 1. 一句話定位

**Kefir 是由「顆粒（grains）」發酵的含酵母發酵乳**，顆粒是細菌與酵母共生、包裹在多醣與蛋白基質中的膠團（SCOBY 型）。優格則由**選定的乳酸菌**發酵，不含酵母。

---

## 2. 與常溫優格的差異

| 項目 | Kefir | 常溫（mesophilic）優格 |
|------|-------|------------------------|
| 微生物 | 細菌 **+ 酵母** | 僅乳酸菌 |
| 載體 | kefir grains（顆粒可回收再用） | 菌粉或前一批成品 |
| 溫度 | 20–25°C 為理想；20–30°C 亦可 | 20–30°C（DIY 常 21–25°C） |
| 時間 | 18–24 h | 12–48 h |
| 質地 | 較稀、可倒可飲 | 依菌種，多為軟凝乳或 custard |
| 產氣／乙醇 | **有**（酵母代謝，微量 CO₂ 與乙醇） | 基本無 |
| 傳代上限 | grains 可無限延續 | direct-set 約 3–5 代 |
| 風味 | 較酸、帶酵母氣息 | 較溫和滑順 |

**溫度雖重疊，但升溫效果不同：** 有綜述指出 kefir 顆粒發酵溫度自 20°C 升到 30°C 時，LAB 與酵母數量都增加、發酵活性提升，而嗜溫性菌群仍保持穩定。這與嗜熱優格菌「低於 40°C 就發不起來」是完全不同的行為模式。

---

## 3. 三種製作路線

| 路線 | 做法 | 特性 |
|------|------|------|
| **傳統顆粒法** | 顆粒直接投入冷卻至 20–25°C 的殺菌乳，18–24 h 後濾出顆粒 | 菌相最豐富；顆粒需約每 24 h 換新鮮乳 |
| **母種法（grain-free）** | 先用顆粒發酵一批並濾除顆粒，取該成品 **1–3%** 接種新鮮乳，19–28°C／24 h | 不必處理顆粒；可延續有限批次 |
| **商業菌粉法** | 選定的 LAB + 酵母凍乾粉，20–25°C／18–24 h | 品質穩定但微生物多樣性較低；**數批後效力衰退需重新補粉** |

工業界常刻意降低酵母比例以避免 CO₂ 累積、改善保存穩定性，代價是風味與傳統 kefir 有落差。目前有多菌株配方試圖還原傳統的微生物複雜度。

---

## 4. 台灣脈絡：kefir 與 730 的關係

家酪優的創辦人於 1993 年與美國菌種公司合作研發 730 菌粉，動機正是要解決當時使用**克菲爾菌種發酵品質不穩定、口味太酸**的問題。

→ 這是理解台灣家用優格市場為何以「中高溫多菌株菌粉」為主流的一條線索：早期 DIY 用克菲爾，因不穩定而被商業配方取代。若你要做 kefir，預期就該是「較酸、較稀、需要照顧顆粒」，而不是拿優格的標準去評分。

## 5. 對本站資料模型的建議

若日後要收 kefir，建議這樣掛：

```js
{
  id: 'milk-kefir',
  temperatureClass: 'mesophilic',
  cultureType: 'scoby',        // 見 01 第 5 節
  reuseHint: 'grains（可無限延續，需約每日換乳）',
  tempRangeC: '20–25',
  timeRangeH: '18–24',
  // ...
}
```

批次紀錄需要**額外欄位**才記得住 kefir：

- `grainToMilkRatio`：顆粒與奶量比（優格的「接種量」不適用）
- `carbonation`：是否產氣、鼓罐程度
- `strainedAt`：濾出顆粒的時間點

→ 若暫時不想擴充 schema，可先只用 `bodyMd` 敘述，等實際做過幾批再決定要不要開欄位。

---

## 6. 邊界說明

- 本章不含水克菲爾（water kefir）與康普茶（kombucha）：同為 SCOBY 型但非乳製。
- 「Kefir 益生菌數量多於優格」的宣稱在通俗文章常見，實際依產品與菌株而異，本站不採用未經核對的數字。
