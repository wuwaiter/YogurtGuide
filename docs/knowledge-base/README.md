## 使用原則

1. 網站公開內容請用自己的話重寫，並可連結／註明參考來源。
2. 同一學名（species）下，**不同廠商菌株（strain）特性仍可能不同**。
3. 「希臘優格」多半是**製程（瀝乳／straining）**，不一定等於特定菌種配方。
4. 台灣法規對「優格」菌種標示未必與美國 FDA／IDFA 定義完全相同；知識庫會並陳差異。
