# 02 — 常見產品型菌種說明（Culture Profiles）

> 綜合英文 DIY／菌種商說明、學術文獻與繁中教學整理。  
> 數值為「常見範圍」，實際以包裝與你的批次為準。

## A. 嗜熱型（Thermophilic）

### A1. 傳統／標準優格菌（Traditional yogurt culture）

| 項目 | 說明 |
|------|------|
| 英文 | Traditional / plain yogurt starter |
| 核心物種 | *S. thermophilus* + *L. delbrueckii* subsp. *bulgaricus* |
| 適溫 | 約 40–45°C（常 42–43°C） |
| 時間 | 約 4–8 h（依酸度目標可拉長） |
| 風味／質地 | 典型優格酸香；可做成凝態或再加工 |
| 備註 | 市售多數「原味優格」與此路線相近 |

### A2. 保加利亞優格（Bulgarian yogurt）

| 項目 | 說明 |
|------|------|
| 英文 | Bulgarian yogurt |
| 核心物種 | 傳統上強調僅 *L. bulgaricus* + *S. thermophilus*（保加利亞產品定義常見此要求） |
| 適溫 | 約 42–43°C（文獻／DIY 常落此區間） |
| 時間 | DIY 常寫 **8–12 h** 可更酸更稠；工業亦有 4–6 h 區間視配方 |
| 風味／質地 | 酸感較明顯、乙醛等優格香氣較突出的形象 |
| 備註 | 同為兩菌共生；差異常在**菌株組合與發酵終點**，不只「有沒有這兩菌」 |

**菌株比例確有實證：** 一篇 2023 年研究把 *L. bulgaricus* : *S. thermophilus* 以 1:1、1:10、1:100、1:1000、1:2000 混合，42°C 發酵至 pH ≈ 4.5，共測出 63 種揮發性化合物；**1:100 組**的風味輪廓與感官評價最接近對照優格。→ 支持「同樣兩菌、不同比例即是不同產品」的說法。

### A3. 希臘優格菌粉（Greek yogurt starter）

| 項目 | 說明 |
|------|------|
| 英文 | Greek yogurt starter |
| 適溫 | 嗜熱區間（約 42–43°C） |
| 訴求 | 較厚、較溫和的凝乳；有些宣稱較少瀝乳即可偏濃 |
| **重要澄清** | 「希臘優格」成品定義上多指**瀝去乳清（strained yogurt）**；菌粉名稱≠保證已是希臘優格 |
| 對照中文市場 | 「希臘式」常加膠體／奶粉增稠，與真正 strained 不同 |

### A4. Skyr（冰島）

| 項目 | 說明 |
|------|------|
| 英文 | Skyr |
| 本質 | **技術上屬新鮮起司（fresh cheese）**，只是被當優格吃 |
| 核心物種 | 嗜熱路線：*S. thermophilus* + *L. delbrueckii* subsp. *bulgaricus*，常宣稱含冰島特有菌株 |
| 適溫／時間 | **42–43°C／6–12 h**（英國供應商說明書寫 42°C、約 10 h；要更酸則拉長） |
| 瀝乳 | **必要步驟。** 冷藏瀝 8–12 h，越久越厚；濃稠來自瀝乳而非菌種 |
| 乳品選擇 | 傳統用**脫脂乳**——少數「脫脂才正宗」的發酵；全脂較濃郁但不傳統 |
| 型態 | 市售家用款多為 heirloom，可長期傳代（每公升留約 1 大匙） |
| 備註 | 傳統做法會加**一滴凝乳酶（rennet）** 幫助結構；發酵中出現乳清分離是正常現象，不是失敗 |

**給批次紀錄的重要提醒：** 供應商明確指出乾粉的**第一批常表現不足**，需用第一批的一匙做第二批才是該菌的真實水準。因此 Skyr（乃至其他凍乾 heirloom）的**第 1 代不應當作基準線**，批次欄位務必記代數。

### A5. 機能加強型（Probiotic-fortified yogurt cultures）

非「風格名」，但市售極常見：在兩大核心菌之外再加：

- *L. acidophilus*（A 菌）
- *Bifidobacterium* spp.（B 菌／比菲德氏菌等）
- *Lacticaseibacillus casei* / *rhamnosus* 等

Tetra Pak 等工業資料亦指出：優格中除兩核心菌外加菌，主因常是**益生／機能訴求**。

## B. 常溫型（Mesophilic / countertop）

共同點：室溫附近發酵、常可 heirloom 傳代；質地多偏稀或特殊黏性；風味多較溫和。

### B1. Viili（芬蘭）

| 項目 | 說明 |
|------|------|
| 適溫 | 約 20–25°C（工業製程寫冷卻至 20°C 後接種、熟成約 20 h） |
| 質地 | 溫和、**ropy／黏絲**（胞外多醣 EPS） |
| 風味 | 偏淡、偏甜潤，帶奶油香 |
| 型態 | heirloom；**不只乳酸菌**（見下） |

**傳統 viili 是 LAB + 黴菌 + 酵母的混合群落**，不是純乳酸菌配方：

| 成員 | 學名 | 角色 |
|------|------|------|
| 產酸乳球菌 | *Lactococcus lactis* subsp. *lactis* | 主要酸化 |
| 產黏乳球菌 | *Lactococcus cremoris*（舊 *L. lactis* subsp. *cremoris*） | **產 EPS，黏絲的來源** |
| 產香乳球菌 | *L. lactis* subsp. *lactis* biovar *diacetylactis* | 雙乙醯（奶油香） |
| 產香明串珠菌 | *Leuconostoc mesenteroides*（subsp. *cremoris*） | 雙乙醯、揮發物 |
| 表面黴菌 | *Geotrichum candidum* | 消耗乳酸；分泌脂解／蛋白解酵素形成 viili 特有風味；表面結成絨毛層；密封杯中耗氧產 CO₂ 使成品微帶氣泡 |
| 酵母 | *Kluyveromyces marxianus*、*Pichia fermentans*、*Saccharomyces unisporus* | 發酵乳糖／半乳糖，酵母香；亦參與 ropy 質地形成 |

**黏絲的物質叫 viilian：** 由產黏 *L. cremoris* 分泌的**含磷雜多醣**，性質類同克菲爾的 kefiran；組成隨菌株而異（半乳糖／葡萄糖／鼠李糖重複單元，到純半乳糖同聚物）。以葡萄糖為基質時產量高於高果糖基質。

**⚠️ ropy 特性會流失：** EPS 合成基因常位於**質體**上，保存或培養溫度偏高即可能丟失。1988 年研究把產黏菌株從 17°C 移到 30°C，黏性由 +++ 掉到幾乎消失；連續傳代 21 代亦出現自發性失黏變異株。

→ **對批次紀錄的意義：** viili 某批不黏，**可能是菌株變異而非操作失誤**。批次欄位建議獨立記「本批是否 ropy」與母種保存溫度。

### B2. Filmjölk（瑞典）

| 項目 | 說明 |
|------|------|
| 適溫／時間 | **20–21°C／18–20 h**（商業菌種商製程建議） |
| 菌相 | *L. lactis* subsp. *lactis*、*L. cremoris*、biovar *diacetylactis*、*Leuconostoc mesenteroides* |
| 質地 | 偏可飲、比牛奶稠但比優格薄；custard／酪乳感 |
| 風味 | 略酸帶奶油香 |
| 備註 | 現代商業配方常另加 *L. acidophilus*、*B. animalis* subsp. *lactis* 做機能訴求 |

與 Viili 的關鍵差別：**Filmjölk 菌相不含黴菌**，且一般不以產黏菌株為主，因此不 ropy。

### B2.5. Onaka（お腹／fil＋bifido）

| 項目 | 說明 |
|------|------|
| 本質 | **瑞典 filmjölk 變體**＋雙歧桿菌；名稱取日文「お腹（肚子）」 |
| 起源 | Arla 約 1990 年上市；與森永合作引入日本 bifido |
| 適溫 | 常溫（mesophilic／fil 型） |
| 市售菌相（Arla Cultura Onaka） | filkultur＋*B. lactis* BB-12®、*L. acidophilus* LA-5®、*L. casei* F-19® |
| DIY starter | 常標 fil-style＋*B. lactis*；風味清爽、酸度偏溫和 |
| 備註 | **≠ Japanese Caspian Sea**（裏海為 *L. cremoris* 單菌主導＋強 EPS）；較接近 Filmjölk 的機能加強版 |

### B3. Japanese Caspian Sea（カスピ海ヨーグルト／日本裏海）

| 項目 | 說明 |
|------|------|
| 適溫 | 室溫（常溫型） |
| 優勢菌 | **單一株 *Lactococcus cremoris* 主導**，10⁸–10⁹ CFU/g |
| 質地 | 黏稠 custard；黏性同樣來自該菌的 EPS |
| 風味 | 溫和、相對「比較像優格」 |
| 備註 | 名義上溯源高加索，但**與原產地 matsoni 不是同一件事**（見 B5）；亦**≠ Onaka** |

日本 2010 年一項調查採集五地共六款樣本，60 個分離株中 59 株為同一株產黏 *L. cremoris*；PFGE 分析顯示可分四個亞群，推測是在日本多年傳代中發生輕微變異。少數樣本另檢出 *Latilactobacillus sakei*、*L. plantarum*、*L. paracasei*、*L. kefiri*、*Leuconostoc mesenteroides*，以及醋酸菌（*Acetobacter aceti*、*Gluconacetobacter sacchari*）。

### B4. Piimä（北歐）

| 項目 | 說明 |
|------|------|
| 適溫 | 室溫區間 |
| 質地 | 很稀、可飲 |
| 風味 | 溫和 |
| 變化 | 有資料建議用鮮奶油培養成偏酸稀奶油用途 |

### B5. Matsoni（喬治亞原產）— 列在此節但**不屬常溫型**

> **本節是 2026-07-31 的修正。** 舊版把 Matsoni 與 Caspian Sea Yogurt 當同義詞並歸為常溫型，文獻不支持。  
> 保留在 B 節是因為英文 DIY 站普遍把它列在常溫風格裡，方便對照查找。

| 項目 | 說明 |
|------|------|
| 溫度歸類 | **不宜歸常溫。** 多篇研究以嗜熱的 *S. thermophilus* + *L. delbrueckii* 為主菌 |
| 菌相 | **不定**，且無標準化菌種 |
| 常見物種 | *L. delbrueckii* subsp. *bulgaricus* / subsp. *lactis*、*L. acidophilus*、*S. thermophilus*、*Lactococcus lactis*、*L. cremoris*，另有 *L. helveticus*、*L. paracasei*、*Leuconostoc lactis* |
| 真菌 | *Geotrichum candidum*、*Kluyveromyces marxianus*、*Saccharomyces*、*Candida* 等 |
| 地理特性 | 2015 年研究指出菌相**隨產地而異但在各地區內穩定**，屬「微生物生物地理」現象 |

**為什麼會被混為一談：** 日本流通的常溫型商品借用了高加索的地名與淵源故事，但其菌相在日本長期傳代後已由單一產黏乳球菌主導。DIY 商店販售的「matsoni starter」實際多半是前者那種常溫乳球菌型。

→ **本站寫法建議：** 菌種頁分成 `caspian-sea`（常溫、乳球菌型、可傳代）、`onaka`（fil＋bifido）、與 `matsoni`（原產、菌相不定、偏嗜熱、含真菌），並互相註明差異。

## C. 台灣市場常見「商品分類」對照（繁中來源）

家酪優等繁中教學常用：

| 商品說法 | 對應知識庫分類 | 適溫／時間（其文） |
|----------|----------------|-------------------|
| 中高溫優格菌 | Thermophilic | ~42°C，4–12 h |
| 常溫優格菌（MESO 等） | Mesophilic | ~25°C（文中亦寫 20–35°C），12–48 h |
| 730 等品牌菌粉 | 多為中高溫商品菌株組合 | 以包裝為準 |

→ 之後你的菌種檔可用「商品名」當 title，並掛 `temperatureClass` + 可能的 style。

### C1. 三款常見商品的實際菌株標示（2026-07-31 補）

> 以下抄自商品頁與經銷商標示，非本站實測。菌株編號為該廠自有命名。

| 商品 | 溫度類別 | 菌株 | 菌數／包 | 建議時間 |
|------|----------|------|----------|----------|
| **MESO 常溫優格菌** | Mesophilic（~25°C） | 5 株：嗜熱鏈球菌 ST30、保加利亞乳桿菌 LB119、乳酸乳球菌乳脂亞種 LLC966、LLL970、副乾酪乳桿菌 LPC48 | 每克 10 億以上 | 12–48 h（室溫） |
| **730 優格菌** | Thermophilic | 11 株：長雙歧桿菌 BL774、嬰兒雙歧桿菌 BLI732、嗜酸乳桿菌 LA323、乾酪乳桿菌 LC331、植物乳桿菌 LP391、保加利亞乳桿菌 LB212、嗜熱鏈球菌 ST110、植物乳桿菌 LP28、鼠李糖乳桿菌 LRH09、長雙歧桿菌 BL986、嗜熱鏈球菌 ST37 | 標示 120 億（廠稱出廠 300–400 億） | 夏 8–12 h／冬 10–16 h |
| **28 安敏優格菌** | Thermophilic | 4 株：植物乳桿菌 LP28、鼠李糖乳桿菌 LRH09、嗜熱鏈球菌 ST37、長雙歧桿菌 BL986 | 標示 200 億（廠稱出廠 600 億以上） | 夏 8–10 h／冬 10–12 h |

三個值得注意的點：

1. **MESO 不是北歐型常溫菌。** 它是「優格兩菌（ST30 + LB119）+ 兩株乳球菌 + 副乾酪乳桿菌」的混搭：靠乳球菌把可用溫區拉低到室溫，而北歐 Viili／Filmjölk 是純乳球菌系＋（Viili）真菌。因此 MESO 屬 **direct-set 純 LAB 型**，不是可長期傳代的 heirloom。廠商亦明確標示 MESO **不建議用優格機**。
2. **28 沒有保加利亞乳桿菌。** 它以抗過敏訴求的 LP28 為主株，靠 ST37 產酸凝乳，配方邏輯已偏離「傳統兩菌」路線——這也解釋了為何它的風味與 730 明顯不同。
3. **兩款中高溫菌都塞了雙歧桿菌與嗜酸乳桿菌**，屬本章 A5 說的機能加強型；這些菌對凝乳貢獻有限，主要是益生訴求。

### C2. 菌粉保存（廠商說明整理）

- **冷凍（-18°C 以下）為最佳**，標示可保存兩年。低溫下乳酸菌休眠、活性維持較好。
- **不可反覆退冰再冷凍**：菌體內水分反覆結晶、融解會降低活性。
- **>50°C 大幅失活。** 夏季常溫貨運車廂、日照下車內（可達 50°C 以上）足以讓菌粉喪失發酵能力。
- MESO 因菌株特性標示可 25°C 存放半年，但台灣夏季常 >35°C，廠商仍建議冷凍。

→ 若某批發酵失敗且無明顯操作失誤，**先懷疑菌粉的運輸／保存溫度**，批次欄位可加一欄記「菌粉來源與到貨方式」。

## D. 快速選型（給實作）

| 你的目標 | 較合理的起點 |
|----------|----------------|
| 接近市售稠優格、可對照文獻 | Thermophilic（傳統／Bulgarian） |
| 想少設備、夏天室溫發酵 | Mesophilic（Viili／Filmjölk／台灣常溫菌） |
| 要希臘濃稠口感 | 先做好嗜熱優格再 **straining**；菌粉選 Greek starter 為加分非必須 |
| 想長期留母種 | Heirloom（需規律製作）；最耐傳代的是含真菌／SCOBY 型 |
| 偶爾做、求穩定 | Direct-set 菌粉 |
| 想要真正「無限」延續 | Kefir grains（見 [05-kefir-and-scoby.md](./05-kefir-and-scoby.md)） |
| 想要黏絲（ropy）口感 | Viili 或 Japanese Caspian Sea（產 EPS 的 *L. cremoris*） |
| 想要 fil＋雙歧、清爽常溫 | Onaka（≠ 裏海） |

## E. 與資料欄位建議對應

之後在 `data/seed-data.mjs` 的 `cultures` 陣列新增時可對齊：

```js
{
  id: '...',
  title: '...',
  titleEn: '...',
  temperatureClass: 'thermophilic', // 或 'mesophilic'
  reuseHint: 'heirloom / direct-set / ...',
  // style 概念可用 id 表達：bulgarian | greek-starter | viili | ...
  species: '...',
  tempRangeC: '40–45',
  timeRangeH: '4–12',
  summary: '...',
  bodyMd: `...`,
  sortOrder: 10,
}
```
